MELO — Personal Music Player for Anki
Version 1.0
Copyright © 2026 Yuki

A personal retro-inspired music player integrated into Anki.

Core features
- LIST / DISC song selection modes
- Persistent library, queue, playlists, recent tracks, and favorites
- Clickable and draggable seek bar
- Shuffle and repeat
- Configurable welcome name and background image
- Visualizer and independent spinning vinyl display
- Compact resizable player designed for the Anki desktop environment

First launch
On first launch, MELO asks “What should I call you?” and uses the answer in the welcome message. Your name is stored only in your local Anki addon configuration.
